# VS IT Solutions

Static business website for VS IT Solutions — enterprise IT, networking, server management, CCTV, laptop repair, cloud backup and corporate AMC services.

## Files

- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — animations, mobile menu, client cards and WhatsApp inquiry form

## Local preview

Open `index.html` directly, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
